# Bedömning av mottagarkapacitet

En bedömning per grupp. Skriv grupper och roller, aldrig namn. Märk varje uppgift **frågat** (från dem eller deras chef) eller **antaget**. Hitta inte på kapacitet.

| Dimension | Fråga | Svar | Frågat / antaget |
| --- | --- | --- | --- |
| Tid och belastning | Har gruppen utrymme nu? Vad kan tas bort om något ska in? | | |
| Kompetens | Vad behöver de kunna? Hur stort är gapet? | | |
| Andra förändringar | Vad annat pågår? Hur många förändringar har de tagit emot nyligen? | | |
| Kritiska perioder | Finns perioder då förändring är olämplig? | | |
| Stöd och ledarskap | Finns en ledare som kan prioritera och stå bakom? | | |
| Erfarenhet och förtroende | Hur gick tidigare förändringar? Finns förtroende för avsändaren? | | |

## Sammanvägd bedömning

| Grupp | Kapacitet (låg / medel / hög) | Skäl | Åtgärd |
| --- | --- | --- | --- |

Åtgärder vid låg kapacitet: minska omfattningen, flytta tidpunkten, lägg till stöd, ta bort något annat, välj en annan grupp att börja med.
