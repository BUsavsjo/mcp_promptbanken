# Beslutsorienterad agenda

Fyll i med användarens egna uppgifter. Skriv "saknas" där uppgiften inte finns. Hitta inte på något.

**Möte:**
**Datum, tid och längd:**
**Deltagare (roller):**
**Mötets syfte:**
**Önskat resultat när mötet är slut:**
**Mandat (vem får besluta vad):**
**Förberedelser före mötet:**

## Agenda

| Tid | Punkt | Syfte | Förväntat resultat (Information / Diskussion / Beslut) | Ansvarig |
| --- | --- | --- | --- | --- |
| | | | | |
| | Sammanfattning: beslut, uppdrag, öppna frågor | Samma bild hos alla | Information | Mötesledare |

Summan av tiderna ska rymmas i mötestiden.

## Underlag att skicka ut i förväg
Sådant som kan läsas före mötet och därför inte behöver tas upp i agendan.

## Det som inte hinns
Punkter som flyttas, med förslag på när eller hur de tas.
