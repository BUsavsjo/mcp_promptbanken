# Routing-first UI (Open 1.3.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Promptbanken's MCP UI routing-first and mobile-friendly: compact "används nu" line for `get_template`, three stepper modes, top-5 mobile package cards, correct `template_count`, `packages` on templates, and routing instructions that say *beskriv behov → routa → börja arbeta*.

**Architecture:** Server changes are small and data-level (`mcp_server.py` payloads, descriptions, routing text). Widget changes are confined to the three HTML files plus small helpers in `bridge.js`. Everything is deployed to the dev container only and verified with a live check and a simulated mobile user test.

**Tech Stack:** Python 3.12 (unittest), hand-written HTML/CSS/JS widgets (MCP Apps bridge), Playwright MCP for browser checks, Docker Compose 1.29 on the VPS (dev project only).

**Spec:** `docs/superpowers/specs/2026-09-27-open-1.3.0-routing-first-ui-design.md` (builds on `docs/superpowers/specs/2026-09-26-open-1.3.0-apps-and-superplan-skill-design.md`).

    """Alla paket en mall ingår i. Ett enda "primärt område" blev fel för mallar

    memberships = _catalog_template_packages(context_keys)
    key = str(template.get("id") or "") or str(template.get("slug") or "")
    found = memberships.get(key) or memberships.get(str(template.get("slug") or ""), [])
