# Promptbanken Open 1.2.2 Area/Package Contract Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bevisa vilket konkret problem den frysta `search_templates.area`-listan löser, vilka upptäcktsvägar den påverkar och om den lokala ändringen ska behållas för Promptbanken Open 1.2.2.

**Architecture:** Granskningen behandlar den godkända 1.2.2-submissionen och dess versionslåsta tool-snapshot som kontraktskälla. Den skiljer sedan på fyra oberoende användarvägar: fritextsökning, det felbenämnda `area`-filtret, paketbläddring och rollrekommendation. Inga produktionsändringar görs innan en evidensmatris och ett uttryckligt behåll/återställ-beslut finns.

**Tech Stack:** Python 3, `unittest`, MCP JSON-RPC, PowerShell-kontraktstest, JSON Schema.

**Spec:** `chatgpt-app-submission.json` och `mcp-server/contracts/promptbanken-open-1.2.2.tools.json`

## Global Constraints

- Promptbanken Open 1.2.2 har exakt nio publika, read-only verktyg.
- Exponerade verktygsnamn, beskrivningar, input/output-scheman, annotations och `_meta` får inte ändras utan ny OpenAI-review.
- `search_templates.area` är i 1.2.2-submissionen en enum med 17 paketslugs, trots fältnamnet `area`.
- Nya paket ska fortfarande kunna hittas via `list_packages`, `get_package`, `list_package_prompts` och relevant fritextsökning.
- Ingen VPS-deploy, push, databasändring eller omskrivning av den godkända snapshoten ingår i denna plan.
- Befintliga orelaterade arbetskopieändringar ska lämnas orörda.
